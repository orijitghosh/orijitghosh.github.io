6Repositories

Research software
& side projects.

R packages and Shiny apps for analyzing sleep and circadian data from Drosophila, plus side projects: hand-drawn plots for ggplot2, a bonsai grown from GitHub history, color palettes, and the code behind this site.

gh repo list orijitghosh → 6 repositories, all public
  • 01 / 06 FlyDreamR An R package to infer sleep/wake states from locomotion data using hidden Markov models. Accompanies our 2026 bioRxiv preprint on the genetic basis of sleep states in Drosophila melanogaster.
    • R
  • 02 / 06 VANESSA-DAM Visualization and ANalysis of timE SerieS dAta — Drosophila Activity Monitors. A suite of Shiny apps for accelerated time-series analysis and visualization of circadian rhythm and sleep data.
    • R
  • 03 / 06 ggsketch An R package on CRAN with hand-drawn geoms for ggplot2: the rough.js sketch look in pure R, with no JavaScript or browser. The geoms work with aes(), stats, scales and facets, and render on every graphics device, PDF included.
    • R
  • 04 / 06 kodama Your GitHub history drawn as a bonsai. Commits grow foliage, merged PRs ripen into fruit and reviews hang lanterns. It's one image URL for your profile README, redrawn every day from your real numbers.
    • HTML
    • TypeScript
    • Astro
    • JavaScript
    • CSS
  • 05 / 06 prakriti An R package on CRAN with color palettes inspired by India's natural landscapes.
    • R
