# CSV File Format Reference

Complete specification for each CSV file in `data/`.

## General rules

- **Encoding:** UTF-8
- **Line endings:** LF or CRLF (either works)
- **Header row:** First row must match the column names below exactly (case-sensitive)
- **Empty cells:** Leave blank for optional fields (e.g., `,,` for two empty cells in a row)
- **Commas in values:** Wrap the entire cell in double quotes: `"a, b, c"`
- **Quotes inside values:** Double them: `"He said ""hi"""`
- **HTML:** Allowed in fields marked "HTML allowed" below

## `publications.csv`

| Column | Required | Description |
|---|---|---|
| `year` | Yes | Year as integer (e.g., `2026`) |
| `title` | Yes | Full paper title |
| `authors` | Yes | Semicolon-separated. Format: `Lastname Firstname`. Your name is auto-bolded based on `config.yaml` → `author_bold_patterns`. |
| `venue` | Yes | Journal/conference name (no italics — added automatically) |
| `url` | No | Link to paper |
| `selected` | No | `yes` to show on home page; otherwise empty |
| `note` | No | Extra text appended to venue (e.g., `Springer`, `preprint`) |

**Example:**

```csv
year,title,authors,venue,url,selected,note
2026,Inferring sleep states with HMMs,Ghosh Arijit; Harbison Susan Tracy,bioRxiv,https://www.biorxiv.org/...,yes,
2024,The Genetics of Sleep,Singh NP; Ghosh Arijit; Harbison ST,In Genetics of Sleep,https://...,yes,Springer
```

**Auto-generated by build script:**
- Sequential numbering (01, 02, ...)
- Year dividers between groups
- Sort by year (descending)
- Animation delays
- Author name bolding

## `news.csv`

| Column | Required | Description |
|---|---|---|
| `date` | Yes | Format: `YYYY-MM` (e.g., `2026-05`). Auto-formatted to `May 2026` for display. |
| `description` | Yes | The news content. **HTML allowed** for links/emphasis. |

**Example:**

```csv
date,description
2026-03,Received the SRBR Merit Award.
2026-01,"Posted a <a href=""https://..."">Preprint</a> on sleep state inference."
```

**Auto-generated:**
- Sorted newest first
- Top N shown on home page (default 7, configurable in `config.yaml`)

## `repositories.csv`

| Column | Required | Description |
|---|---|---|
| `name` | Yes | Repository name |
| `description` | Yes | Brief description. **HTML allowed** for `<em>`, `<strong>`, etc. |
| `url` | Yes | Full GitHub URL |
| `languages` | No | Comma-separated list (e.g., `R` or `"Ruby, HTML"`). Wrap in quotes if multiple. |

**Example:**

```csv
name,description,url,languages
FlyDreamR,An R package to infer sleep states.,https://github.com/orijitghosh/FlyDreamR,R
mysite,Personal website built with <em>Jekyll</em>.,https://github.com/orijitghosh/mysite,"Ruby, HTML"
```

**Language colors:** Defined in `config.yaml` → `language_colors`. Add new ones if needed.

## `education.csv`

| Column | Required | Description |
|---|---|---|
| `start_year` | Yes | Start year (e.g., `2016`) |
| `end_year` | Yes | End year, or `present` |
| `degree` | Yes | Degree name (e.g., `Ph.D.`) |
| `institution` | Yes | Institution and location |
| `details` | No | Pipe-separated bullets (e.g., `Bullet 1|Bullet 2`). **HTML allowed.** |

**Example:**

```csv
start_year,end_year,degree,institution,details
2016,2022,Ph.D.,"JNCASR, Bengaluru, India",A Tale of Two Chronotypes — <em>Drosophila</em> chronotypes
```

## `experience.csv`

| Column | Required | Description |
|---|---|---|
| `start_year` | Yes | Start year |
| `end_year` | Yes | End year, or `present` |
| `title` | Yes | Position title |
| `institution` | Yes | Lab / institution |
| `details` | No | Pipe-separated bullets. **HTML allowed.** |

**Example:**

```csv
start_year,end_year,title,institution,details
2022,present,Postdoctoral Fellow,"Lab of Systems Genetics, NHLBI",Did A|Did B|Did C
```

## `awards.csv`

| Column | Required | Description |
|---|---|---|
| `year` | Yes | Year of award |
| `description` | Yes | Award description. **HTML allowed.** |

**Example:**

```csv
year,description
2026,SRBR Merit Award
2025,Sleep Research Society Scholar Award
```

**Auto-generated:** Sorted newest first.

## `service.csv`

Combines editorial, NIH service, mentoring, and teaching into one file using a `category` column.

| Column | Required | Description |
|---|---|---|
| `category` | Yes | One of: `editorial`, `service`, `mentoring`, `teaching` |
| `description` | Yes | The activity. **HTML allowed.** |
| `order` | No | Display order within category. Lower = first. Defaults to row order. |

**Categories:**

| Category value | Renders under section |
|---|---|
| `editorial` | `// editorial & review` |
| `service` | `// service at nih` |
| `mentoring` | `// mentoring` |
| `teaching` | `// teaching` |

**Example:**

```csv
category,description,order
editorial,"Editorial Board at <span class=""highlight"">SLEEP Advances</span>",1
mentoring,Mentored a postbac at NIH from 2023–2024,1
teaching,Taught the basic chronobiology course at JNCASR,1
```

## `config.yaml`

Static personal info and display options.

Key sections:

- **Personal info:** `name`, `email`, `location`, `designation`, etc.
- **`bio`:** list of HTML paragraphs shown on the home page
- **`tags`:** list of strings shown as pills on the home page
- **`author_bold_patterns`:** list of name strings to auto-bold in publications
- **`language_colors`:** map from language name to hex color
- **`home_page`:**
  - `news_count`: how many news items to show on home (default 7)
  - `selected_publications_count`: max selected pubs on home (default 6)
  - `typing_text`: prefix for the typing animation

After editing `config.yaml`, run `python build.py` and commit.

## Editing tips

### Microsoft Excel
- ⚠️ Save as **CSV UTF-8 (Comma delimited)**, not plain CSV.
- Excel may strip leading zeros (e.g., `01` becomes `1`) — not a problem here since the build script formats numbers as needed.

### Google Sheets
- File → Download → Comma-separated values (.csv).
- UTF-8 by default. Recommended for non-English characters.

### LibreOffice Calc
- Save As → Text CSV → set encoding UTF-8, separator `,`, text delimiter `"`.

### VS Code / text editor
- Easiest for small edits or HTML in cells.
- Get the "Rainbow CSV" extension to color-code columns.

## Common HTML patterns

```html
Link: <a href="https://example.com">link text</a>
Italic: <em>italic text</em>
Bold: <strong>bold text</strong>
Inline code: <code>function()</code>
Highlighted: <span class="highlight">highlight</span>
```

In CSV, HTML inside a cell with commas/quotes needs the cell wrapped in quotes:

```csv
description
"Posted <a href=""https://..."">paper</a> with co-authors."
```
